# Network

网络请求主流组合：

| 组件         | 职责                                                       |
| ------------ | ---------------------------------------------------------- |
| **OkHttp**   | 底层 HTTP 客户端:连接池、超时、重试、缓存、拦截器          |
| **Retrofit** | 在 OkHttp 之上,把 HTTP 接口声明成 Kotlin 接口              |
| **序列化库** | JSON ↔ Kotlin 对象:Kotlin Serialization(推荐)、Moshi、Gson |
| **协程**     | Retrofit 原生支持 `suspend` 函数,请求结果直接返回          |

```
Repository
   │ 调用 suspend 函数
   ▼
Retrofit 接口 (NoteApi)       ← 声明有哪些请求
   │
   ▼
OkHttp (拦截器、超时、缓存)    ← 真正发请求
   │
   ▼
服务器
```

## 权限

```kotlin title="AndroidManifest.xml"
<uses-permission android:name="android.permission.INTERNET" />
<!-- 需要判断网络状态时再加 -->
<uses-permission android:name="android.permission.ACCESS_NETWORK_STATE" />
```

```kotlin
dependencies {
    implementation("com.squareup.retrofit2:retrofit:$retrofit_version")
    implementation("com.squareup.okhttp3:okhttp:$okhttp_version")
    implementation("com.squareup.okhttp3:logging-interceptor:$okhttp_version")

    // JSON:Kotlin Serialization(需启用 kotlin-serialization 插件)
    implementation("org.jetbrains.kotlinx:kotlinx-serialization-json:$serialization_version")
    // Retrofit 与 Kotlin Serialization 的转换器,
    // 新版 Retrofit 官方已提供 converter-kotlinx-serialization,
    // 旧版用 Jake Wharton 的 retrofit2-kotlinx-serialization-converter,请以官方文档为准
    implementation("com.squareup.retrofit2:converter-kotlinx-serialization:$retrofit_version")
}
```

**明文HTTP**

Android 9+ 默认**禁止明文 HTTP**,只允许 HTTPS。开发期连本地服务器需要在 `network_security_config` 中单独放行,**正式版请一律用 HTTPS**。

## 基本用法

第一步：定于数据模型（DTO）

```kotlin
@Serializable
data class NoteDto(
    val id: Long,
    val title: String,
    @SerialName("body") val content: String,       // JSON 字段名与属性名不同时用 SerialName
    @SerialName("created_at") val createdAt: Long,
    val tags: List<String> = emptyList()            // 给默认值,字段缺失时不崩溃
)

@Serializable
data class CreateNoteRequest(val title: String, val body: String)
```

第二步：定义接口

```kotlin
interface NoteApi {

    @GET("notes")
    suspend fun getNotes(
        @Query("page") page: Int,
        @Query("size") size: Int = 20
    ): List<NoteDto>

    @GET("notes/{id}")
    suspend fun getNote(@Path("id") id: Long): NoteDto

    @POST("notes")
    suspend fun createNote(@Body request: CreateNoteRequest): NoteDto

    @PUT("notes/{id}")
    suspend fun updateNote(@Path("id") id: Long, @Body request: CreateNoteRequest): NoteDto

    @DELETE("notes/{id}")
    suspend fun deleteNote(@Path("id") id: Long)
}
```

第三步：创建Retrofit实例

```kotlin
val json = Json {
    ignoreUnknownKeys = true      // 服务器多返回字段时不报错(强烈建议开启)
    coerceInputValues = true      // null 对应非空且有默认值的属性时,使用默认值
}

val okHttpClient = OkHttpClient.Builder()
    .connectTimeout(15, TimeUnit.SECONDS)
    .readTimeout(30, TimeUnit.SECONDS)
    .writeTimeout(30, TimeUnit.SECONDS)
    .build()

val retrofit = Retrofit.Builder()
    .baseUrl("https://api.example.com/")          // 必须以 / 结尾
    .client(okHttpClient)
    .addConverterFactory(json.asConverterFactory("application/json".toMediaType()))
    .build()

val noteApi: NoteApi = retrofit.create(NoteApi::class.java)
```

第四步：调用

```kotlin
viewModelScope.launch {
    val notes = noteApi.getNotes(page = 1)    // suspend:挂起等待,不阻塞主线程
    ...
}
```

**Retrofit 的 `suspend` 函数是主线程安全的**:内部已在 OkHttp 的线程池执行网络请求,你不需要再套 `withContext(Dispatchers.IO)`

## with Hilt

```kotlin
@Module
@InstallIn(SingletonComponent::class)
object NetworkModule {

    @Provides @Singleton
    fun provideJson(): Json = Json { ignoreUnknownKeys = true; coerceInputValues = true }

    @Provides @Singleton
    fun provideOkHttp(): OkHttpClient =
        OkHttpClient.Builder()
            .connectTimeout(15, TimeUnit.SECONDS)
            .readTimeout(30, TimeUnit.SECONDS)
            .apply {
                if (BuildConfig.DEBUG) {
                    addInterceptor(HttpLoggingInterceptor().apply {
                        level = HttpLoggingInterceptor.Level.BODY
                    })
                }
            }
            .build()

    @Provides @Singleton
    fun provideRetrofit(client: OkHttpClient, json: Json): Retrofit =
        Retrofit.Builder()
            .baseUrl(BuildConfig.BASE_URL)
            .client(client)
            .addConverterFactory(json.asConverterFactory("application/json".toMediaType()))
            .build()

    @Provides @Singleton
    fun provideNoteApi(retrofit: Retrofit): NoteApi = retrofit.create(NoteApi::class.java)
}
```

注意:

- **OkHttpClient 和 Retrofit 必须是单例**。每个 `OkHttpClient` 都有自己的连接池和线程池,重复创建会浪费资源、降低性能。
- **日志拦截器只在 Debug 打开**,`Level.BODY` 会把请求和响应内容(包括令牌、用户数据)全打到 Logcat,正式版绝不能开。

## 响应与错误处理

```kotlin
// ① 直接返回 T:成功返回数据,失败(非 2xx / IO 错误)抛异常
@GET("notes/{id}")
suspend fun getNote(@Path("id") id: Long): NoteDto

// ② 返回 Response<T>:不对 HTTP 错误抛异常,自己检查状态码
@GET("notes/{id}")
suspend fun getNoteResponse(@Path("id") id: Long): Response<NoteDto>
```
